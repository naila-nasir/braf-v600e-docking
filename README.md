Project 1: BRAF V600E Molecular Docking

Question: Which compounds bind best to the BRAF V600E protein, and do they bind better than the known drug vemurafenib?

Aim: Download the BRAF V600E structure, prepare it, check my docking setup, dock known BRAF drugs and my test compounds, and compare their binding scores and interactions.

Tools: RCSB PDB, PubChem, PyMOL or UCSF Chimera, AutoDock Vina, PLIP, SwissADME, Zotero, GitHub
